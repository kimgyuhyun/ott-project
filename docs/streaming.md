# 스트리밍 (HLS 서명 재생)

영상은 오브젝트 스토리지에 올린 다화질 HLS 이고, 접근은 **발급 게이트 + 엣지 검증** 2단으로 막는다.
security.md 와 같은 원칙을 따른다 — 비밀값, 실제 호스트, 우회에 직접 쓰일 값은 적지 않는다.

## 왜 서명 URL인가

원본 스토리지를 공개해 두면 URL 하나가 새는 순간 누구나 무제한으로 받아간다. 멤버십으로 재생 권한을
나눠도 의미가 없어진다. 그래서 스토리지 공개 접근을 완전히 끄고, 서명된 요청만 통과하는 엣지를
유일한 경로로 뒀다.

## 구조

```
브라우저 ──① 재생 요청──▶ 백엔드 (PlaybackAuthService)
                              │ canStream: 무료화수 / 멤버십 판정
                              ▼
         ◀─② master.m3u8 서명 URL (e·st 부착)
            │
            └──③ 서명 URL──▶ Cloudflare Worker (edge/hls-worker)
                                │ 만료·서명 검증 → 실패 시 403
                                ▼
                              R2 (공개 접근 차단)
                                │
         ◀─④ 응답. m3u8 이면 하위 URI에 Worker가 서명을 붙여 되씀 ─┘
```

- **① 발급 게이트** — `PlaybackAuthService.canStream` 이 로그인·공개여부·화수·멤버십을 보고
  서명 URL을 줄지 말지 결정한다. 여기서 막히면 서명 자체가 안 나온다.
- **② 서명 대상은 `master.m3u8` 하나뿐** — 백엔드는 진입점만 서명한다
  (`HlsSignedUrlUtil`, URL-safe base64 무패딩).
- **③ 엣지 검증** — Worker 가 만료와 서명을 검증한다. 백엔드가 아니라 엣지에서 거르므로
  위조·만료 요청은 오리진에 닿지도 않는다.
- **④ 캐스케이드 서명** — 응답이 재생목록이면 Worker 가 본문의 하위 URI(자식 재생목록·세그먼트)에
  직접 서명을 붙여 되쓴다.

## 캐스케이드를 택한 이유

세그먼트는 수백 개고 ABR 이라 어떤 화질을 고를지도 재생 중에 바뀐다. 대안은 이랬다.

| 방식 | 문제 |
|---|---|
| 세그먼트마다 백엔드에 서명 요청 | 재생 중 수백 회 왕복. 백엔드가 재생 경로에 상주하게 됨 |
| 서명 쿠키 발급 | 스토리지·엣지가 쿠키를 신뢰해야 하고, 경로 깊이 규칙이 따라붙음 |
| 경로 프리픽스 단위 서명 | 한 번 새면 그 아래 전부 열림. 만료 단위가 거칠어짐 |

캐스케이드는 백엔드 왕복을 **재생당 1회**로 줄이면서 세그먼트 단위 서명을 유지한다. 대신 서명 로직이
백엔드와 Worker 두 곳에 존재하므로, **서명 포맷이나 시크릿을 바꾸면 반드시 양쪽을 같이 배포해야 한다.**

## 만료(TTL)

캐스케이드는 master 의 만료값을 하위 세그먼트까지 물려준다. 즉 TTL 은 "URL 이 유효한 시간"이 아니라
**한 번 시작한 재생 세션이 살아 있어야 하는 시간**이다. 짧게 잡으면 일시정지·탐색 중에 세션 한복판에서
403 이 난다. 최장 콘텐츠 재생 시간에 여유를 더한 값을 쓴다 (실제 값은 `PlaybackAuthService`).

## 화질

접근 제어는 허용/차단만 한다. 화질별 티어링은 두지 않아, 통과한 사용자는 동일한 ABR 사다리를 받는다.
플레이어가 대역폭에 맞춰 고르는 구조라 서버가 화질을 잘라내면 ABR 이 망가진다.

## 관련 파일

- 발급·권한: `backend/.../service/PlaybackAuthService.java`
- 서명 유틸: `backend/.../util/HlsSignedUrlUtil.java`
- 엣지: `edge/hls-worker/` (배포는 해당 README)
- 시크릿 `SECURE_LINK_SECRET` 은 백엔드 `.env.enc` 와 Worker secret 양쪽에 동일 값으로 존재한다

## 운영 시 주의

- 스토리지 공개 접근(Public URL)이 다시 켜지면 이 설계 전체가 무력화된다. 우회 경로가 생긴다
- 재생이 200 인데 화면이 안 나오면 CSP `media-src` 를 먼저 본다 (네트워크는 통과, 브라우저가 차단)
- 서명 검증 실패는 403 이다. 만료(오래 열어둔 탭)와 위조가 같은 코드로 나오므로 시각을 함께 본다
