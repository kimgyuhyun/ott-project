# 아키텍처 결정 기록 (ADR)

결정 하나당 파일 하나. **왜 그렇게 했는지**와 **무엇을 포기했는지**를 남긴다.
"어떻게 동작하는가"는 `docs/` 의 다른 문서에 있고, 여기는 그 구조를 고른 이유만 적는다.

새 결정은 번호를 이어서 추가한다. 기존 결정을 뒤집을 때는 파일을 고치지 말고
새 ADR 을 쓰고 이전 것의 상태를 `대체됨(→ NNNN)` 으로 바꾼다.
